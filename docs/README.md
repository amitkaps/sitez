# docs

The writing that spans Sitez's files. Each code file's own reasoning is in its `@prose` block.

- [idea.md](idea.md) is the spec: what Sitez promises, its rules, and what's not in v1.
- [sitez.md](sitez.md) is how Sitez, the site layer, is built, and what was ruled out.
- [elementz.md](elementz.md) is the element: one `@name.html` file with its markup, CSS and
  behavior, which Sitez renders and Pagez would too.
- [plan.md](plan.md) is the order of the work, with what's done and what's next.
- [pagez.md](pagez.md) is the idea for Pagez, the single-page layer below Sitez, kept in step with
  it until Pagez is built.
